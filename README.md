# 星遇 Live · 直播交友 App

> 一个「直播 + 充值 + 即时通讯 + 在线交友」的完整产品交付：可直接体验的交互 Demo + 产品 PRD + 原生 App 技术方案蓝图 + 本地真实推流套件。

## 在线体验

**https://badwritten-cn.github.io/star-live-mvp/** （手机浏览器打开体验最佳）

单文件 H5 演示版，全流程可跑通：登录 → 看播互动 → 充值送礼 → 任务签到 → 开播赚收益 → 提现 → 广场交友。

## 目录结构

| 路径 | 说明 |
|---|---|

## 功能一览

**C 端（观众）**
- 首页直播列表（14 位主播 / 8 个分类）、关注横幅、搜索
- 直播间：弹幕、进场动效、点赞飘心、**礼物连送 ×10 + combo 特效**、贡献榜、PK 对抗条、3 个连麦麦位、分享面板
- 充值：8 档金额 + 自定义金额，模拟微信/支付宝支付确认流程
- 钱包：🪙 星币（消费）+ 💎 收益（提现）双账户、账本流水、等级成长
- 广场动态（发布/点赞/评论）、他人主页、邂逅滑动匹配（超级喜欢 / 配对成功）
- 私聊：表情包、语音条、会话置顶/删除、未读计数
- 签到任务：7 天连续签到 + 每日任务埋点领奖

**主播端（同一 App 内嵌，抖音/快手模式）**
- 开播准备（标题 + 分类）→ 主播间（时长/观看/礼物收益实时看板）→ 下播结算（分成 50% 入 💎）

**底座**：localStorage 持久化（`starlive_v2`），刷新不丢数据。

## 本地真实直播（ffmpeg）

```bash
cd realstream
./run.sh test              # 彩条测试画面（无需摄像头权限）
./run.sh cam               # 电脑摄像头 + 麦克风
./run.sh screen            # 屏幕录制
./run.sh file <视频路径>    # 循环推本地视频文件
# 然后打开 http://127.0.0.1:8081/player.html
```

已验证端到端可用：H.264 + AAC、GOP 1 秒、秒开缓存、端到端延时约 1-3 秒。
详细参数与生产化替换方案见 `realstream/README.md`。

> GitHub Pages 是纯静态托管，无法运行流媒体服务端，因此真实推流能力需要在本机运行 `realstream/`。
